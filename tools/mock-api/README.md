# Заглушка API

`mock-api.mjs` — минимальная замена REST API движка: отдаёт заранее заготовленные
данные (команда Пони, игра «Схватка это чудо», уровни pinky_pie / fluttershy /
rainbow) на те эндпоинты, которые нужны фронтенду.

Нужна, чтобы поднять интерфейс без бэкенда: посмотреть вёрстку, поправить стили,
пройтись по экранам, снять скриншоты для документации.

## Запуск

```sh
npm run mock        # заглушка на :8099
npm run start:mock  # ng serve с proxy.mock.json, который шлёт /api на заглушку
```

Дальше открыть http://localhost:4200 — приложение считает, что вы вошли как
`bomzheg`, капитан команды Пони и автор игры «Схватка это чудо».

Обычный `npm start` работает как раньше и ходит на тестовый стенд
(`proxy.config.json`).

## Что внутри

Данные лежат прямо в `mock-api.mjs`, одним объектом `routes`: ключ — метод и путь,
значение — тело ответа (или функция от URL, если ответ зависит от query).
Неизвестный путь возвращает 404 и печатает `MISS GET /что-то` в консоль — так
видно, какой эндпоинт ещё нужно добавить.

Временные метки считаются от текущего момента, поэтому счётчики вроде «уровень
начался 17 минут назад» выглядят правдоподобно в любой день. Даты отдаются в UTC
с `Z`, как и настоящий API.

`MODE=waivers npm run mock` переводит игру в статус сбора вейверов — так видно
блок вейверов, которого во время игры уже нет.

## Скриншоты для документации

Скриншоты веб-интерфейса в документации движка сняты с этой заглушки, скриптом
из `docs/tools/web-shots` репозитория
[bomzheg/Shvatka](https://github.com/bomzheg/Shvatka). Если меняются тексты
заглушки или вёрстка — скриншоты стоит переснять.
